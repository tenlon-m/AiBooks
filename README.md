# AiBooks - AI 全自动小说撰写软件

基于免费在线 AI 大模型的全自动小说撰写桌面软件。支持从创作参数设定到全书批量撰写的完整写作流程，并配备命名生成器、时间线管理、情感曲线分析等辅助工具，让 AI 成为您的写作助手。

> 面向开发者的「功能完成度分析 / 缺陷清单」请见 [docs/功能完成度分析.md](docs/功能完成度分析.md)。

## 快速开始

### 安装与启动

```bash
# 方式一：按 pyproject.toml 安装（推荐开发用）
pip install -e .
aibooks

# 方式二：按锁定版本安装（离线/可复现部署用）
pip install -r requirements.txt
python -m src.app
```

> 需要 Python >= 3.12.0+。测试依赖见 `requirements-dev.txt`（`pip install -r requirements-dev.txt`）。

启动后进入**工程管理器**初始页面，可新建项目或打开已有项目。

### 首次使用三件事

1. **配置 AI 源（必须）**：点击工具栏第二行「AI源配置」，添加至少一个可用 AI 源并启用。软件已预置多个国内免费中文大模型，勾选启用即可；也可配置本地 Ollama 模型。
2. **新建项目**：在工程管理器点击「新建项目」，填写书名等信息。可选择写作模板（玄幻升级流 / 都市重生流 / 穿越种田流 / 系统流）快速启动。
3. **按流程写作**：按工具栏第一行按钮从左到右依次操作即可完成一本书。

## 写一本小说：主流程七步走

工具栏第一行为撰写小说的主流程按钮，按顺序操作：

```
创作参数 → 人物管理 → 大纲管理 → 爽点钩子 → 风格库 → 撰写 → 章节编辑/校验 → 导出
```

> 每页顶部通常有一个**思路输入栏**，可输入您对该步骤的要求，AI 会将其作为额外约束融入生成结果。

### 第一步：创作参数

设定全书基本框架：

1. 填写**书名**（不可与已有项目重名）
2. 填写**故事梗概**（全书故事主线，建议 200 字以上，越详细 AI 生成质量越高）
3. 填写**世界观**（力量体系、社会结构等）
4. 设置**卷数、每卷章节数、每章字数**
5. 点击「创建项目」或「保存工程」

本页提供的辅助按钮：

| 区域 | 按钮 | 说明 |
|------|------|------|
| 梗概 | 导入梗概文件 | 从 txt / md / docx / xlsx 导入已有设定 |
| | AI润色 | 把简短思路扩写成完整梗概 |
| | 保存梗概 | 单独保存梗概 |
| 世界观 | 导入世界观文件 | 同上，导入已有世界观文档 |
| | 从命名收藏导入 | 把命名生成器收藏的地点/势力名追加到世界观 |
| | AI润色 | 扩写世界观 |
| | 保存世界观 | 单独保存世界观 |
| 人物设定 | 导入人物设定文件 | 导入后需到**人物管理**页用「人物及关系自动识别并导入」二次识别 |
| 工程 | 创建项目 / 保存工程 / 删除当前项目 | 项目级操作 |

> **世界观模板**：人物管理页底部提供修仙 / 武侠 / 末日 / 星际四套预设世界观，选好后点「应用模板」一键写入。

### 第二步：人物管理

1. **AI 提取主角**：点击「提取主角」，AI 从梗概 / 世界观中自动提取
2. **AI 生成配角**：点击「生成配角」，配角自动匹配世界观
3. **AI 文件导入**：点击「人物及关系自动识别并导入」，支持 txt / md / docx / xlsx 设定文档，AI 自动识别人物与关系
4. **手动添加**：点「添加人物」或在表格中双击行编辑
5. **确认入库**：勾选后点「确认选中人物」，未确认的人物不会参与后续生成
6. **命名参考**：点「命名生成器」入口可批量生成符合世界观的名字

#### 配角作用域

为适配分层大纲模式，配角可设置**作用域**，控制其在哪些层级范围内出场：

| 作用域 | 说明 |
|--------|------|
| 全书 | 在全书所有章节均可出场（主角与核心配角默认值） |
| 某卷 | 仅在指定卷内活动，其他卷不引入 |
| 某大篇 | 仅在指定大篇内活动（分层大纲模式下可用） |
| 某中篇 | 仅在指定中篇内活动（分层大纲模式下可用） |

- **已有人物默认「全书」作用域**，无需额外设置即可兼容原有流程
- **单元配角**（某卷 / 某大篇 / 某中篇）仅在本单元活动，生成某单元章节时只引入该单元配角 + 全书核心角色，避免配角泛滥
- **主角必须全书可见**，不可设为单元级；如尝试将主角设为单元级会提示拒绝
- **名字全书唯一**，不允许同名人物出现在不同作用域

### 第三步：大纲管理

1. **生成大纲**（二选一）：
   - 「AI整体生成大纲」：一次性生成全书
   - 「AI分批生成大纲」：**推荐长篇使用**，每批若干章并携带前文衔接上下文，实时显示进度，可「暂停」/「续写」
2. **校验与修复**：点「校验一致性」，弹出报告窗口，可「一键修复」让 AI 自动处理问题
3. **场景细化**：选中章节点「细化场景」，把单章拆成 3-5 个场景（目标 / 出场角色 / 关键事件 / 情绪基调 / 预计字数）；「批量细化场景」可一次处理多章并用「暂停批量场景」中止
4. **一键填充出场人物**：AI 根据正文/梗概补全每章的出场人物，供后续一致性校验使用
5. **编辑**：双击任意节点或点「编辑选中」修改章节梗概，改完点「保存大纲」
6. **拖拽排序**：在大纲树上直接拖拽卷 / 章调整顺序，会自动重新编号并检测时间线冲突
7. **清空大纲**：需要重来时使用

> **历史顺序约束**：历史类故事的大纲严格按历史节点顺序生成，不跨阶段混搭。

#### 分层大纲模式

除默认的两级大纲（卷 → 章）外，还支持**五级分层大纲**，适用于超长篇（500+ 章）的精细规划：

| 层级 | 叙事职责 | 篇幅范围 |
|------|----------|----------|
| 分卷 | 全书最高层划分，每卷承载一条主线或大阶段 | 101 - 500 章 |
| 大篇 | 卷内大段落，对应一个完整剧情弧 | 21 - 100 章 |
| 中篇 | 大篇内中等段落，对应一个子剧情 | 5 - 20 章 |
| 小篇 | 中篇内小段落，聚焦一个事件或场景群 | 2 - 4 章 |
| 章纲 | 最底层，即单章梗概（与两级模式的章一致） | 1 章 |

- **分层模式为可选**，默认仍为两级模式（卷 → 章），向后兼容；旧工程打开后仍为两级，可在大纲页手动启用分层
- **逐层生成操作**：先生成**分卷** → 再生成**大篇** → 再生成**中篇** → 再生成**小篇** → 最后生成**章纲**，每一层依赖上一层已生成的内容
- **上层改动 → 下层自动标记需重新生成**：例如修改某大篇梗概后，其下所有中篇 / 小篇 / 章纲会被标记为「待重新生成」，以红色提示
- **每层可暂停 / 续写**：生成过程中可随时暂停，之后从断点继续，已完成内容不丢失

### 第四步：爽点钩子

1. 点「AI逐章生成」，AI 为每章生成**爽点**（读者爽感来源）与**钩子**（悬念），并规划钩子回收章节（跨卷回收 ≤ 3 卷）
2. 生成过程可「暂停」/「续写」；重新打开页面时会自动检测进度并提示可继续
3. 点「校验一致性」检查基调与回收逻辑，报告窗口支持「一键修复」
4. 双击表格行可直接编辑爽点 / 钩子内容，改完点「保存」
5. 「批量删除」可按选中行批量清理

### 第五步：风格库（可选但推荐）

1. 点「选择语料文件」投喂您喜欢的作者范文（单篇 ≥ 1000 字，支持多篇）
2. 填写风格库名称，点「投喂建立」，AI 提取**叙事视角 / 语言风格 / 对话风格 / 句式特征 / 用词习惯 / 节奏控制**六维特征
3. 「查看详情」可查看提取结果；「导出」/「导入」用于在多台电脑间迁移风格库
4. 撰写时在撰写页的下拉框选中该风格库，AI 生成正文将模仿该风格

### 第六步：撰写（批量生成正文）

1. 先在顶部「▼ 撰写思路与风格设置」面板中：填写撰写思路、点「加载风格库」并选择风格
2. 点「开始撰写」，AI 逐章生成正文，**每章完成即实时显示**在预览区与日志中
3. 需要中断时点「暂停」，之后点「续写」从断点继续，已完成章节不丢失
4. 撰写时自动应用风格库约束与去 AI 化约束（贴近真人写作风格）
5. 生成内容即刻落盘保存，断电只丢正在生成的那一章

撰写页其他工具：

| 按钮 | 说明 |
|------|------|
| 校验一致性 | 对已撰写章节做一致性校验，报告窗口支持「一键修复」 |
| 批量补写 | 一键为字数不足章节扩写补全，支持暂停/续写（字数不足章节以红色标记） |
| 保存 | 把预览区的本地修改提交落库（详见下方说明） |
| 刷新章节列表 | 重新拉取章节与完成状态 |
| AI对话 | 打开右侧 AI 对话侧栏，可针对选中段落或整章提问，含改写 / 建议 / 讨论 / 剧情走向四个快捷操作 |
| 查看场景 | 打开当前章节的场景大纲面板 |
| 批量查找替换 | 全书 / 按范围替换，支持正则与区分大小写，先预览后确认 |
| 生成摘要 / 批量生成摘要 | 为章节生成摘要（暂停摘要可中止批量任务） |
| 统计图表 | 快捷跳转到字数统计页 |
| 右键菜单 | 在预览区选中段落后右键，可「续写 / 扩写 / 缩写」，结果可「替换原文」或「插入到原文后」 |

> **关于「保存」**：预览区是只读的，正文只能通过右键「续写 / 扩写 / 缩写」后选择替换或插入来修改。产生修改后按钮会高亮提示，点击「保存」才会写入数据库（每次保存会生成一条版本快照）。

> **补全优化说明**：章节字数不足时，用「批量补写」一键扩写补全至目标字数；剧情与大纲不符时，用「校验一致性」→ 报告窗口「一键修复」。两者相互独立，可先后执行。

#### AB稿 / ABC稿多AI纠错

撰写页支持**多 AI 纠错模式**，通过多个 AI 源交叉校验提升正文质量：

| 模式 | 说明 |
|------|------|
| off | 关闭多 AI 纠错（默认），单源直接生成正文 |
| AB | A 稿生成 → B 稿 AI 纠错 → 评估 AI 评分，取较优者 |
| ABC | A 稿生成 → B 稿 AI 纠错 → C 稿 AI 再纠错 → 评估 AI 评分，取较优者 |

- 在撰写页顶部「▼ 撰写思路与风格设置」面板中切换纠错模式（off / AB / ABC）
- **每步可选不同 AI 源**：A 稿、B 纠错、C 再纠错、评估分别可指定不同模型，实现互补纠错
- **默认关闭**，启用后每章生成耗时约为单源的 2-3 倍，请确保 AI 源充足

#### 迭代生成

支持**按卷 / 阶段 / 章迭代**生成，每次迭代基于上次结果改进：

- 在撰写页设置**迭代次数**（输入框）与**单位**（卷 / 阶段 / 章）
- 点「迭代生成」按钮启动，AI 按指定粒度逐轮生成，每轮基于上一轮结果改进
- 适用于追求高质量成稿的场景，迭代次数越多耗时越长

### 第七步：章节编辑与校验

**章节编辑页**工具栏：

| 按钮 | 说明 |
|------|------|
| 刷新章节列表 | 重新拉取章节 |
| 保存并再校验 | 保存正文后自动触发 AI 一致性再校验 |
| AI润色 | AI 润色当前章节，以**并排预览**展示修改前后 |
| 采纳润色 / 拒绝润色 | 确认或放弃润色结果 |
| 校验一致性 | 单章一致性校验 |
| 阅读模式 | 以书籍排版预览，可调字体 / 行距 / 背景（含护眼模式） |
| 批量查找替换 | 全书 / 按范围替换，支持正则，先预览后确认 |
| 版本管理 | 每次保存自动生成版本快照，可对比差异、回滚、手动标记重要版本 |
| 锁定 | 锁定已定稿章节防止误改（只读，需确认解锁） |
| 批注侧栏 | 右侧批注面板，支持添加 / 编辑选中 / 标记失效，按状态筛选 |
| 合并章节 | 把多个**相邻**章节合并为一章（可自定义标题，留空由 AI 生成） |
| 拆分章节 | 按字符偏移把当前章拆成多章，可用「使用光标位置」快速定位拆分点 |
| 衔接优化 | 分析相邻两章的衔接（评分 / 问题清单），生成过渡段并可一键插入 |

> 合并与拆分都会先为原章节自动生成版本快照，随时可在「版本管理」中回滚。

> **补写 vs 一键修复**：补写针对字数（撰写页「批量补写」），一键修复针对一致性（撰写页「校验一致性」→ 报告窗口「一键修复」），二者相互独立、可先后执行。

**编辑器内右键菜单**：选中段落后可「续写 / 扩写 / 缩写」与「添加批注」。

**校验报告页**：

- 「全书校验」：执行 7 维一致性校验（梗概 / 世界观 / 人物 / 钩子 / 物品 / AI化 / 风格），生成问题清单与整体评分，并给出 AI 化程度评估
- 「批量再校验」：只针对指定章节重做校验，一次最多 50 章（可输入要校验的章数，默认取最后 N 章）
- 「刷新列表」：重新拉取最近一次校验结果

### 最后：导出

小说导出页支持 **TXT / DOCX / EPUB / Markdown / PDF** 五种格式。

**导出前置条件（重要）**：

1. 项目状态必须为「已完成」
2. 全部章节都必须生成完成且有正文

不满足条件时导出会直接失败并给出提示，请先回到撰写页补齐章节。

**导出选项**：

- **排版模板**：出版风格 / 简洁风格 / 网文风格（三套，每套覆盖不同格式的字体、字号、行距、标题样式、首行缩进、页眉页脚）
  - 注意：**TXT 格式不使用排版模板**，导出为纯文本；其余四种格式才会应用模板
- **导出选项**：章节分页、包含大纲、包含角色设定、封面页
- 选择目标目录后点「导出小说」，完成后显示生成文件路径

## 辅助工具按钮详解（工具栏第二行）

### 命名生成器

按世界观批量生成候选名称，支持五类：**角色 / 地名 / 势力 / 物品 / 功法**。默认一次生成 10 个，可调整数量。

- 双击候选行即标记为收藏，收藏列表按类型筛选
- 收藏可一键导出到别处：
  - 「导入到人物管理」——角色名直接进人物表
  - 「导入到物品管理」——物品 / 功法名进物品表
  - 「追加到世界观」——地点 / 势力名追加到世界观末尾

### 时间线管理

维护小说事件的时间先后顺序。每个节点含**事件名、时间点、涉及角色、关联章节、描述**。

- 在横向时间轴上**拖拽节点**即可调整顺序，调整后自动落库
- 点「冲突检测」自动检查时序冲突（例如某角色在死亡事件之后仍然出场）
- 大纲页拖拽排序时也会联动做同样的检测

### 角色关系图谱

以节点 + 边的图形化方式展示人物关系网络，支持**亲属 / 师徒 / 朋友 / 敌对 / 主仆 / 情人 / 自定义**七类关系。

- 点「自动提取」可从人物设定文本自动生成关系
- **手动维护**：右侧「关系列表」选中一行后，可用「新增关系 / 编辑选中 / 删除选中」自行增删（删除立即生效，无需再点保存）
- 勾选 / 取消关系类型可筛选显示
- 点击节点查看角色详情
- 图上的修改点「保存」提交（保存为全量替换，清空列表会二次确认防止误删）

### 情感曲线分析

AI 逐章分析**紧张度**与**情绪起伏**（0-100），生成全书情感折线图（双 Y 轴），辅助把控节奏。

- 选择「全书」或「指定章节」范围后点「生成情感曲线」，SSE 实时显示进度并增量绘图
- 只有**已完成且有正文**的章节会被分析；章节正文过短时该章会被跳过并在进度条给出说明
- 点「刷新」重新拉取已保存的曲线

### 字数统计

三个维度可视化：各章字数柱状图、按卷字数饼图、日均写作量趋势线，另含目标完成度进度条。撰写页有「统计图表」快捷入口。

> 本页为纯统计展示，不调用 AI，数据随撰写进度实时变化。

### 物品管理

集中维护全书物品（武器 / 丹药 / 功法 / 法宝等）。

- 「新增物品 / 编辑选中 / 删除选中」，双击行也可编辑
- 字段：名称、类型、关键属性、持有者、首次出场（卷 / 章）
- 「一致性检查」排查同名不同类型等问题
- 除手动维护外，撰写时 AI 会自动提取新物品入库，也可从「命名生成器 → 导入到物品管理」批量导入

### 敏感词检测

内置**政治 / 暴力 / 色情**三类词库，可自定义增删。

- 点「全书扫描」标记所有命中位置（章节 / 段落 / 偏移），提供替换建议
- 双击命中项会跳转到该章节并在正文中高亮定位首个命中词

### 历史回滚

所有修改记录（手动编辑 / AI润色 / 批量替换等）均可回滚。

- 选择章节后列出该章全部修改历史
- **选中一行会在下方「内容预览」显示该次修改后的正文**
- 点「回滚到选中记录」一键恢复，回滚后会展示再校验结果

### AI源配置

管理多个 AI 源（在线 OpenAI 兼容接口 + 本地 Ollama）。

- **启用 / 禁用、优先级、权重**设置
- **四种路由策略**：
  - **手动指定**——固定使用某个源
  - **故障转移**——主源失败自动切备用（按优先级，权重不生效）
  - **负载均衡**——按权重分发（权重生效，优先级不生效）
  - **成本优先**——优先选择低成本源
- 8 个预置模型可一键填充表单，选中后自动带上推荐的「适用任务」标签
- API Key **密文存储**（Fernet 加密，密钥文件权限 600），保存即测试连通性
- Ollama 本地模型**动态发现**，自动列出已安装模型
- 「导出配置」/「导入配置」用于多台电脑间迁移 AI 源

> 测试连接后会弹出「模型画像」窗口，展示该模型的特点与推荐任务，可一键应用推荐。

### 全局设置

通过菜单栏「工具→设置→打开设置」打开统一设置窗口，包含：

- **乱码检测开关**：启用后生成内容会自动检测并标记乱码字符
- **定时自动保存**：开关与保存间隔（1-30 分钟），即时生效

通过菜单栏「工具→全局主题」打开主题设置窗口，可切换亮色/暗色主题、配色方案与字体大小，即时预览并全局生效。

### AI调用日志

查看每次 AI 调用的**模型、场景、耗时、状态、提示词与响应详情**，便于排查生成质量问题。点「查看详情」查看单条完整记录。

### 应用日志

管理程序运行日志（`data/logs/` 目录）：查看文件列表与内容、按级别（INFO / WARNING / ERROR）筛选、关键词过滤、导出、清理历史日志。

### 备份管理

- **备份策略**：备份目录、定时 Cron、保留份数、退出时触发、危险操作前触发（打开页面会自动回填当前策略）
- **立即备份 / 恢复选中备份 / 删除选中备份**
- **项目导出 / 导入**（`.aibk` 归档，包含创作参数、人物、大纲、爽点钩子、风格、正文、版本、批注、时间线等**全部**项目数据；**API Key 不导出**）

### 快捷键配置

查看 / 修改 / 启停所有快捷键，冲突自动检测。「重置为预设」恢复默认。

> 双击某一行修改后**立即写入数据库**，不存在「待保存」的改动，「保存」按钮仅用于说明这一点。

## 一键拆书

将已有小说（他人作品或自己的旧稿）上传，AI 自动拆解为多级大纲与要素，可用于学习分析或作为二创基础。

### 操作步骤

1. **上传文件**：支持 **txt / pdf / epub / docx** 四种格式，点击「选择文件」或拖拽到上传区
2. **AI 拆解大纲**：点击「开始拆书」，AI 逐层逆向归纳，从正文反推出**分卷 → 大篇 → 中篇 → 小篇 → 章纲**五级大纲
3. **提取五类要素**：拆书同时自动提取以下要素：
   - **人物**：角色名、身份、关系、性格特征
   - **时间地点**：事件发生的时间与场景
   - **世界观**：力量体系、社会结构、规则设定
   - **物品**：武器、丹药、法宝、关键道具
   - **事件**：重要剧情事件及其因果链
4. **查看拆书结果**：大纲树与要素列表分栏展示，可展开 / 折叠各层
5. **基于拆书结果二创**：点击「创建新工程」，系统会以拆书结果预填新工程的大纲与要素，在此基础上改写创作

> 拆书结果可导出为 JSON，方便跨工程复用。二创工程与原拆书结果独立，修改不会影响原结果。

## 降AI率改写

针对**朱雀**等 AI 率检测器的改写功能，通过变换句式与用词降低 AI 检测率，同时保持语义不变。

### 操作步骤

1. **选择章节**：在章节列表中勾选需要改写的章节（支持多选）
2. **选择策略**：三种策略可组合使用：
   - **句式变换**：调整句子结构（主动 ↔ 被动、长句拆短句、合并散句等）
   - **同义替换**：用同义词 / 近义词替换高频 AI 特征词
   - **口语化处理**：加入口语化表达、语气词，降低机械感
3. **改写**：点击「开始改写」，AI 按选定策略逐章改写，实时显示进度
4. **原文与改写文对比**：每章改写完成后弹出**并排对比**窗口，左原文右改写
5. **采纳 / 回退**：对比后可选择「采纳」写入改写文，或「回退」保留原文；支持逐章决定

> 改写仅调整表达方式，不改变剧情与语义。建议改写后用「校验一致性」确认未引入偏差。

## 自动保存与数据安全

程序有两套保存机制：

1. **定时自动保存**：默认每 **5 分钟**保存一次工程配置（可在「工具→设置→打开设置」中修改间隔或关闭）
2. **关键节点保存**：以下操作完成后会自动触发一次保存
   创作参数保存、人物合并、大纲保存、爽点钩子保存、命名收藏、场景细化、每章撰写完成、校验完成、时间线变更、关系图谱变更、情感曲线生成、敏感词扫描、润色确认

**断电/死机会丢内容吗？** 生成内容每章 / 每批即时落盘，自动保存负责工程配置。断电最多丢正在生成中的那一章，重启后在撰写页点「续写」即可。

**自动保存失败会怎样？** 连续失败 3 次会弹出告警。SQLite 锁冲突等可恢复错误会计入次数；连接类不可恢复错误只记录日志与状态栏提示，不打扰。

## 已知限制与规避方法

以下是当前版本中**已知的功能缺口或限制**，列出以便您提前规避。完整的技术分析、文件行号证据与缺陷分级请见 [docs/功能完成度分析.md](docs/功能完成度分析.md)。

| 限制 | 影响 | 规避方法 |
|------|------|----------|
| **TXT 导出不应用排版模板** | TXT 为纯文本 | 需要排版请选 DOCX / EPUB / Markdown / PDF |
| **情感曲线跳过正文过短的章节** | 曲线可能不连续 | 补齐章节正文后重新生成 |
| **批量再校验一次最多 50 章** | 长篇需分批 | 分多次执行，或用「全书校验」 |
| **合并章节要求相邻** | 不相邻会报错 | 先用大纲页拖拽排序，或改用大纲调整后再生成 |
| **字数统计页不含 AI 分析** | 该页为纯统计 | 无需规避，忽略即可 |
| **AI 输出被截断 / 章节字数低于目标** | 部分章节字数不足 | 撰写页「批量补写」一键扩写补全至目标字数 |

> 若遇到功能异常（例如按钮点击无反应），可先查看「应用日志」与「AI调用日志」定位原因。

## 常见问题

**Q: AI 生成超时怎么办？**

各场景已内置独立超时（撰写、大纲、校验、润色等各不相同）。若免费源仍超时，可在 AI源配置 调大该源的超时秒数，或启用「故障转移」策略自动切换备用源。

**Q: 提示"无可用 AI 源"？**

撰写 / 批量生成前会检测可用 AI 源。请到 AI源配置 启用至少一个源并通过连通性测试。

**Q: 内容少于 50 字？**

AI 返回内容不足 50 字时返回 422 错误并提示，可点击重试。情感曲线分析遇到这类章节会跳过并在进度条说明。

**Q: 免费模型输出被截断？**

软件已按"逐章生成、即时返回"设计避免超长输出。若单章仍被截断，可尝试更换模型或降低每章字数。

**Q: 章节字数不足如何批量补齐？**

在撰写页点「批量补写」，AI 会自动为字数不足的章节扩写补全至目标字数。字数不足的章节在列表中以红色标记。补写支持暂停/续写，暂停后再次点击会重新计算不足集合，已达标章节自动排除。

**Q: 补写与一键修复的区别？**

补写针对**字数不足**（在原章基础上扩写补充至目标字数，不改剧情主线）；一键修复针对**一致性偏差**（根据校验问题清单修复偏离大纲/风格的内容）。两者相互独立，可先后执行。

**Q: 导出失败提示章节未完成？**

导出要求项目状态为「已完成」且全部章节都有正文。请在撰写页确认所有章节状态为「已完成」，缺失的章节可点「续写」补齐。

**Q: 如何迁移到另一台电脑？**

两条路径：
1. **项目迁移**：备份管理 → 项目导出（`.aibk`）→ 拷贝到新电脑 → 项目导入。全部数据（含版本 / 批注 / 时间线）都会带过去。
2. **AI 源迁移**：AI源配置 → 导出配置 → 新电脑导入配置。**API Key 不会随项目导出**，需在新电脑重新填写。

**Q: 打包运行（exe）后提示「API 404: Not Found」？**

说明路由模块没被打包进 exe，通常是修改了 `aibooks.spec` 的 `hiddenimports` 后未重新打包。
`aibooks.spec` 中必须保留 `collect_submodules('src.api.routers')`：路由是运行时动态导入的，PyInstaller 静态扫描不到。
重新执行 `pyinstaller aibooks.spec` 即可；排查时可查 `data/logs` 里的「路由注册完成，但有 N/34 个模块未注册」。

**Q: 断电 / 死机会丢内容吗？**

生成内容每章 / 每批即时落盘，自动保存负责工程配置。断电最多丢正在生成中的那一章，重启后在撰写页点「续写」即可。

**Q: 修改了很多章节，为什么「保存」提示没有待保存内容？**

撰写页预览区是只读的，只有通过右键「续写 / 扩写 / 缩写」并选择「替换原文」或「插入到原文后」才会产生待保存修改。直接改正文请到**章节编辑页**，那里有「保存并再校验」。

**Q: 关闭程序时提示后台任务进行中？**

例如 AI 大纲生成这类长任务仍在执行。选择「是」会等待它们完成（最长 60 秒），选择「否」会中断。

**Q: 分层大纲与传统大纲的区别？**

分层大纲是**可选的增强模式**，默认仍为两级（卷 → 章）。旧工程打开后仍为两级模式，可在大纲页选择启用分层。启用后可逐层生成分卷 → 大篇 → 中篇 → 小篇 → 章纲，不启用则按原有两级流程操作，两者向后兼容。

**Q: 多AI纠错的配置建议？**

建议 **A 稿用大参数模型**（如 Qwen2.5-32B）保证生成质量，**B / C 纠错用不同模型**互补纠错（例如一个擅长语法、一个擅长逻辑），**评估用第三个模型**客观打分。在撰写页「▼ 撰写思路与风格设置」面板中为每步分别指定 AI 源。默认关闭，按需启用。

**Q: 降AI率改写的效果说明？**

针对**朱雀**等 AI 率检测器优化，通过**句式变换、同义替换、口语化处理**三种策略降低 AI 检测率，保持语义不变。改写后可在检测平台复测验证效果。建议组合使用多种策略，并改写后用「校验一致性」确认未引入剧情偏差。

## 技术栈与目录结构

- Python 3.12 + PySide6 + FastAPI + Uvicorn
- SQLAlchemy 2.0 + SQLite（41 张表）+ httpx
- Jinja2（56 个外置提示词模板，修改即热重载）+ matplotlib + python-docx + EbookLib + reportlab

```
src/
├── ui/           # PySide6 UI 层（26 页面 + 36 控件 + 9 主题模块）
├── api/          # FastAPI 路由层（41 个路由模块，含 16 个 SSE 流式端点）
├── services/     # 业务服务层（47 个服务 + 4 个导出器）
├── ai/           # AI 网关（多模型路由 / 适配 / 重试 / 熔断 / 日志）
├── db/           # 持久化层（SQLAlchemy ORM + 9 个迁移，41 张表）
├── backup/       # 备份 / 迁移（.aibk 归档，全表覆盖）
├── config/       # 配置与加密（Fernet）
├── prompts/      # Jinja2 提示词模板（56 个）
├── templates/    # 预设资源（写作模板 / 世界观模板 / 排版模板 / 敏感词库）
└── utils/        # 工具（异步桥接 / 日志 / 兼容补丁）
```

**架构说明**：程序启动时会先在本机后台线程启动 FastAPI 服务（`127.0.0.1:8765`），再启动 Qt 界面。界面所有操作都通过 HTTP 调用后端 API，AI 调用统一走 `src/ai/gateway.py` 网关（含路由策略、重试、熔断与调用日志）。
